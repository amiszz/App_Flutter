# Aplicativo Flutter

Aplicativo com cadastro, login e recuperação de senha usando Firebase Authentication.

## Etapa 1 — Configuração
- **O que foi feito:** configuração do Firebase e desenvolvimento do aplicativo.
- **Uso de IA:** Foi usada como apoio para integrar o Firebase Authentication ao Flutter, revisar textos e desenvolver o aplicativo.
- **Sugestões da IA:** orientações sobre como integrar o Firebase ao projeto, complementadas pela documentação oficial do Firebase. Também ajudou a verificar os arquivos, pois a conexão com o Flutter não estava funcionando como esperado.
- **Alterações e aprendizados:** revisei e adaptei o exemplo da IA ao projeto durante o desenvolvimento das telas. Também aprendi mais sobre Flutter e sua integração com outros serviços.

## Tecnologias utilizadas
